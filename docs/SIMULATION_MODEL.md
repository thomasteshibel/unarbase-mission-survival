# Simulation model

The module uses simplified educational assumptions for a lunar habitat environment. These values are simulated and not intended to represent verified NASA measurements.

## Resource model

- Oxygen: crew members consume oxygen according to a daily rate scaled by mission day and difficulty.
- Water: water demand accounts for hygiene, hydration, and recycling losses.
- Food: food demand tracks crew calories and rationed reserve use.
- Power: power is generated from solar collectors and reduced by mission activity and emergency loads.

## Radiation model

Radiation values are randomized within a range chosen to create instructive risk. The model is intentionally educational and should not be interpreted as a forecast of actual space weather.

## Important safety note

The simulator distinguishes clearly between simulated educational values and observed scientific data. Future NASA datasets may be integrated only after validation, source checking, and measurement-unit verification.
